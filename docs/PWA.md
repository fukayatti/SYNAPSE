# FesFlow PWA・オフライン対応

最終更新: 2026-10-21

## 現在の対応

- Web App Manifest、アプリアイコン、ホーム画面への追加案内、更新案内を用意しています。
- Service Worker はアプリのHTML、全ルートのJavaScript/CSS、アイコンを保存します。初回に一度オンラインで開けば、読み込み済みの画面シェルをオフラインでも開けます。
- API応答、注文履歴、来場者情報、アップロード画像は共有端末に残さないため、Service Worker のキャッシュ対象外です。
- モバイル注文は IndexedDB の送信待ち領域へ保存し、同じ注文キーで再送します。注文がサーバーに届いたか不明な場合は注文履歴で確認し、同じ内容を新規注文として重ねて送らないでください。
- オフライン中はヘッダーに赤い状態表示を出します。接続復帰後に注文を送信している間は緑色で進捗を表示します。保存に失敗した注文は送信待ちと区別して表示します。
- 来場者には注文完成、お知らせ、イベント終了後のレビュー依頼を、スタッフにはイベント告知、販売商品の在庫アラート、公開されたシステムお知らせを通知します。来場者のお知らせはアプリ内にも保存され、通知履歴から確認できます。

## 通知を有効にする

Push通知にはVAPID公開鍵と秘密鍵が必要です。キーは環境ごとに一組だけ用意し、秘密鍵をリポジトリや画面に貼り付けないでください。

- ローカル開発では `apps/api/.dev.vars` に `VAPID_PUBLIC_KEY` と `VAPID_PRIVATE_KEY` を設定します。このファイルはコミットしません。
- CloudflareではAPI Workerの `VAPID_PUBLIC_KEY` と `VAPID_PRIVATE_KEY` をWorker secretとして設定し、API Workerをデプロイします。D1 migrationも通常のリリース手順に従って適用します。
- `VAPID_SUBJECT` は省略でき、省略時は `mailto:admin@fesflow.shikosai.net` を使います。運用連絡先を変える場合はWorkerの環境変数として設定します。
- 来場者は通知ページまたはアカウント画面、スタッフはスタッフ通知設定から、自分で通知を有効にします。許可ダイアログはボタン操作後にだけ表示します。
- 来場者向けPWAでは、通知が未設定またはブロック中の場合に各画面で通知設定を案内します。通知ページを開いて案内を閉じると、現在のタブでは再表示しません。
- iPhone/iPadではSafariの共有メニューからFesFlowをホーム画面に追加し、そのアイコンから開いて通知を設定してください。

プッシュ配信の鍵が未設定でも、来場者のお知らせ履歴とスタッフの既存通知一覧は利用できます。

イベント終了後のレビュー依頼は、API Workerの日次Cronで対象イベントを確認します。Cronは毎日UTC 02:00（日本時間11:00）に実行されるため、依頼の到着は開催終了から最大約24時間遅れることがあります。

## オフライン時の制約と残作業

- イベント情報、メニュー、在庫、来場者のサーバー注文履歴はオフライン用に保存していません。オフラインでアプリの枠組みは開けますが、最新データの取得はオンライン接続が必要です。
- 注文以外のサークル・イベント設定、出欠、システム管理の更新はオフライン送信待ちにしません。通信エラーが表示された操作は保存済みとみなさず、再接続後に内容を確認して保存してください。
- 送信待ち注文はアプリを再び開いた時に同期します。アプリを閉じた状態でのバックグラウンド同期は実装していません。
- オフライン注文の再送でも、価格・在庫・販売期間などの最新条件はサーバー側で再確認が必要です。競合時に利用者へ選び直してもらう画面と、共有端末で個人データを安全に保持する設計は今後の課題です。
- プッシュ通知はブラウザ、OS、権限設定、ネットワーク事業者に左右されます。重要な案内はアプリ内通知履歴も確認してください。

## ローカル確認

```bash
bun run setup:local
bun run dev:api
bun run dev:app
```

APIは `http://localhost:8787`、アプリは `http://localhost:3000` で開きます。Vite開発サーバーでは本番用Service Workerを登録しません。Service Worker、オフラインキャッシュ、インストール動作は `bun run build` 後の静的成果物をHTTPSで配信して確認してください。
