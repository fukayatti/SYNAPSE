# 当日運用マニュアル（リストバンド管理）

最終更新: 2026-10-13
対象: 受付担当、来場者対応担当、イベント管理者
関連: [イベント管理マニュアル](./当日運用マニュアル_イベント管理.md)

## この画面で行うこと

イベント管理画面の「リストバンド管理」で、来場者の受付、リストバンドの照会・紛失ロック・再発行、来場者プロフィールの修正を行います。画面は `/event/dashboard` の左メニューにあります。イベント管理者から当日の担当者へ役割を割り当て、アカウント情報やQRコードを扱う範囲を必要最小限にしてください。

## 開場前の準備

1. 管理画面のヘッダーで対象イベント名を確認します。別イベントを選んだまま操作すると、別イベントの来場者を扱います。
2. 「リストバンド管理」を開き、来場者一覧が表示されることを確認します。表示されない、権限エラーになる場合は、イベント管理者へ連絡してください。
3. 物理リストバンドを使う場合は、事前に登録済みのバンドIDと印刷済みQRの対応が合っていることを確認します。未登録の場合は、イベント管理者が「リストバンドURL CSVを取り込む」または「人数を指定してID生成」で登録します。ID生成・CSV取込は来場者枠とバンドを登録する操作です。現場で必要になった分だけを登録し、同じIDを重ねて取り込まないでください。
4. セルフ受付を使う場合は、画面の「受付用セルフ登録QR」を表示・掲示し、対象イベントの受付URLであることを確認します。個別対応では「個別に発行」を使います。
5. 当日の担当を分けます。本人確認と来場者検索を行う担当、交換用バンドを渡す担当、例外判断をする責任者を決め、紛失処理やアカウント制限は責任者が確認してから実行してください。
6. 管理画面を使う端末の通信とログインを確認します。スタッフ間でログイン情報を共有せず、画面を離れるときは端末をロックしてください。

## 受付の基本手順

### 物理リストバンドで受付する

1. 来場者にリストバンドのQRを読み取ってもらいます。登録済みのバンドであれば、初回はプロフィール登録、登録済みの来場者はマイページへ進みます。
2. 来場者が読み取れない場合は、スタッフが管理画面の「登録情報スキャン・照会」でバンドのQRを読み取るか、バンドIDを入力して照会します。
3. 照会結果の呼出ID・ニックネーム等を来場者に確認し、本人と対象データが一致する場合だけ案内を続けます。似たニックネームだけで判断しないでください。
4. 未知のID、登録済みIDとの重複、別人に紐付いたバンドが出た場合は、別のバンドを試して重ねて登録せず、受付責任者へ引き継ぎます。

### スマートフォンだけで受付する

- 来場者自身がQRから受付する場合は「受付用セルフ登録QR」を案内します。読み取り後にスマートフォン用IDが発行され、プロフィール登録に進みます。
- スタッフが個別に発行する場合は「個別に発行」→「アカウントを発行する」を選びます。表示されたQRを来場者本人のスマートフォンで読み取ってもらい、本人の画面でマイページまたはプロフィール登録が始まることを確認します。
- 既に来場者アカウントがある人をスマートフォン用IDへ切り替える場合は、対象者の詳細を開き、「スマホ用リストバンドIDを発行」を使います。既存の有効な物理バンド・スマホ用バンドは置き換えられるため、本人と対象アカウントを確認してから実行してください。
- 発行済みQRやチェックインURLは、その来場者本人へ直接渡してください。掲示板、共有チャット、写真、公開ログへ載せないでください。

## 来場者を検索・照会する

1. 「登録来場者一覧」から「一覧を開く」を押します。
2. 呼出ID、ニックネーム、好きな日付、バンドIDなど、来場者が提示した情報で検索します。必要に応じてバンド種別・アカウント状態・プロフィール状態のフィルターを使います。
3. 呼出IDとニックネーム等、複数の情報を照合してから、対象行の「編集」を押します。
4. 一覧ではアカウント状態とバンド状態を確認できます。`BAN` はアカウント制限、`紛失` / `再発行済` / `無効` はバンド状態です。目的に合う状態か確認してください。
5. 作業後に一覧へ戻り、同じ呼出IDの状態が更新されたことを確認します。

## 紛失したとき

紛失したバンドは、第三者が使えないようにロックし、新しいバンドまたはスマートフォン用IDへ切り替えます。本人の特定と交換在庫の確認を先に行ってください。

1. 来場者に呼出ID・ニックネームなどを確認し、必要なら「登録情報スキャン・照会」で提示されたIDを照会します。来場者本人との対応が確認できるまで、アカウントやバンドを変更しません。
2. 対象の来場者詳細を開き、表示された呼出IDと現在のバンドIDを再確認します。
3. 一覧の「紛失」操作、または詳細のステータスを「紛失 (Lost / ロック)」に変更します。紛失ロック後、そのバンドでは利用できなくなります。
4. 物理バンドを交換する場合は、新しい交換用バンドのQRを詳細画面の「物理リストバンドの新規紐付け・再発行」で読み取るか、コード値を入力して「登録」を押します。登録が成功すると、古い有効バンドは自動的に無効化されます。
5. 物理バンドを使わず本人のスマートフォンで利用する場合は「スマホ用リストバンドIDを発行」を使います。既存の有効なバンドは置き換えられます。画面の状態が「スマホ用」になったことを確認し、本人への利用案内方法が分からない場合は責任者へ確認してください。
6. 物理バンドを交換した場合は、新しいバンドのQRを読み取ってもらい、新しいIDで利用できることを確認します。交換したバンドIDと紛失したバンドIDを取り違えないでください。
7. 処理できない場合は、重複登録や紐付け解除を試さず、責任者へ対象の呼出ID・画面に出たエラー・実施した手順を伝えます。バンドIDや来場者IDそのものは共有しないでください。

### 紛失とアカウント制限の違い

- **紛失 (Lost)**: そのバンドをロックします。紛失したバンドの利用を止める目的で使います。
- **アクセス禁止 (Banned)**: 来場者アカウント全体を利用制限します。バンド紛失時に代わりに設定するものではありません。イベント責任者の判断なしに変更しないでください。
- **紐付け解除 (Unlink)**: バンドを来場者から外し、バンド状態も無効化します。紛失・交換時の通常手順では使わず、責任者の指示がある場合だけ実行してください。

## プロフィールを修正する

1. 一覧で呼出ID・ニックネーム等を照合し、該当する来場者の「編集」を押します。
2. 呼出ID、ニックネーム、好きな日付、アカウント状態のうち、本人確認や運用上必要な項目だけを修正します。呼出IDは重複できません。
3. 「プロフィール情報を保存」を押します。バンド状態の変更は別の操作です。
4. 保存完了を確認し、詳細を開き直して変更内容を確認します。保存前に閉じると、未保存のプロフィール変更は破棄されます。
5. 好きな日付は紛失時の本人確認に使う情報です。画面表示・口頭確認は必要な範囲に留め、本人以外へ伝えないでください。

## 終了時の確認

1. 受付責任者と、交換・紛失対応件数、未解決の問い合わせを照合します。
2. 未解決案件は、来場者の呼出ID、本人と確認した方法、実施済みの処理、画面のエラーを責任者へ引き継ぎます。IDやQR値は記録・共有せず、必要な場合は権限のある管理画面で照会してください。
3. 印刷用CSV、チェックインURL、画面キャプチャなど、当日の受付に使った来場者資格情報を端末・共有領域に残さないよう、責任者の管理手順に従って片付けます。
4. 受付端末からログアウトまたは画面ロックし、使用した交換用バンドの残数を担当責任者へ報告します。

## よくある状況と対応

| 状況 | 対応 |
|---|---|
| QRを読み取っても開けない | カメラ権限、通信、QRの印字状態を確認し、スタッフ照会へ切り替えます。入力したコードが見つからない場合は再発行をせず、責任者に確認します。 |
| 「該当する来場者が見つからない」 | バンドIDの入力誤り、別イベントのバンド、未登録を確認します。対象イベントとコードを責任者が照合し、必要なら事前登録フローで登録します。 |
| 登録済みID・重複のエラーが出る | 同じCSVやIDを繰り返し取り込まず、バッチ履歴と対象の来場者を責任者が確認します。重複を避けるため、新しい交換用IDの判断を受けてください。 |
| 変更ボタンが使えない、権限エラーになる | 対象イベントの選択とログイン状態を確認します。権限を自分で変更しようとせず、イベント管理者へ引き継ぎます。 |
| 画面の処理結果が分からない | 同じ操作を連打せず、一覧を再読み込みして現在のバンド状態を確認します。表示されたエラーと時刻を責任者へ伝えます。 |
| 紛失者の本人確認ができない | バンドやアカウントを変更せず、責任者へ引き継ぎます。本人確認用の日付や既存の登録情報を、周囲に聞こえる形で読み上げないでください。 |

## 個人情報・QRの取り扱い

- バンドID、来場者ID、チェックインURL、QRコードは、知っている人が来場者として操作できる情報です。本人への提示・読み取り以外に使わず、コピー・撮影・転送・公開をしないでください。
- 管理画面の来場者一覧にはニックネームや本人確認用の日付が表示されます。受付担当以外に見せず、画面を放置しないでください。
- CSVやURLを扱う場合は、イベント運営が指定した端末・保存場所だけを使い、共有先を限定してください。不要になった作業用ファイルやダウンロードを残さないでください。
- 誤った来場者を編集した、QR/URLを第三者へ渡した、または紛失バンドが引き続き使えた疑いがある場合は、直ちに操作を止め、発生時刻・状況をイベント責任者へ報告してください。
